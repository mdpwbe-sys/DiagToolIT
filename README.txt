📦 CONTENU DU PACKAGE :
--------------------------------------------------------------------------
1. [Lancer Diagnostic IT UAA3.bat]
   -> Lanceur rapide en 1 clic (Double-cliquez dessus).
   -> Gère automatiquement l'élévation des privilèges Administrateur (UAC).

2. [Diag-IT-UAA3-V3.ps1]
   -> Moteur PowerShell complet de diagnostic L3 et de génération de rapport.
   -> Peut être exécuté directement en ligne de commande :
      powershell -ExecutionPolicy Bypass -File .\Diag-IT-UAA3-V3.ps1

3. [Guide_UAA3 .pdf]
   -> Guide méthodologique et support de référence IT Niveau 3 (UAA 3).

--------------------------------------------------------------------------
⚡ EXÉCUTION & PRÉREQUIS :
--------------------------------------------------------------------------
- Système requis : Windows 10 ou Windows 11 (64 bits).
- PowerShell : Version 5.1 (intégrée à Windows) ou PowerShell 7+.
- Droits : Privilèges Administrateur requis pour les sondes matérielles/L3
  (le script demande l'élévation UAC automatiquement).
